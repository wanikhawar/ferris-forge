Ownership Caves · Copy or move?

fn main() {
    let a = 5;
    let b = a;
    let s1 = String::from("hi");
    let s2 = s1;
    println!("{} {}", a, b);
    println!("{}", s2);
}
Answer: A

i32 is Copy, so a and b both hold 5. s1 was moved into s2, but s1 is never used again, so there's no error. Moving isn't a problem by itself; only using the old name afterwards is.

Ownership Caves · Scope

fn main() {
    let outer = String::from("outer");
    {
        let inner = String::from("inner");
        println!("{} {}", outer, inner);
    }
    println!("{} {}", outer, inner);
}
Answer: C

inner only exists inside the inner { }. At the } it is dropped and its name is gone, so the last line is error E0425. Rust catches this at compile time, so it can never become a use-after-free at runtime.

Borrow Bridge · The three keys: Read, Write, Own

fn main() {
    let mut v = vec![1, 2, 3];
    let first = &v[0];
    v.push(4);
    println!("{}", first);
}
Answer: B

first borrows from v, so v loses its Write permission until first's last use on line 5. v.push(4) needs Write, so it's error E0502. Pushing could reallocate the vector and leave first dangling, which is exactly the bug Rust prevents.

04 · How it works

A real compiler, and a crab who can only talk.

⚙️ Real compiler
Your code runs through your own rustc. The compiler and tests decide whether you pass, not the AI.
🦀 Ferris = Claude
Explanations, hints, reviews and chat go through claude -p, so they use your Claude subscription. No API key.
🧠 Pick a brain
Switch Ferris between Fable, Opus, Sonnet and Haiku, and choose an effort level.
⚡ Energy bar
The “E” bar shows how much of your Claude usage limit is left. Offline mode uses built-in hints and costs nothing.
🔒 Local only
Listens on 127.0.0.1, and its API only answers the game's own page. Each run is limited in memory, CPU time and file size, and stopped after 5 seconds.
✅ Every level verified
cargo run -- verify checks that every starter fails, every solution passes, and every book topic is taught.

06 · Questions

Before you set sail

Do I need Claude to play?

No. Without Claude Code, switch Ferris to offline mode in Settings and he gives built-in hints. Every level is still compiled and checked the same way.

Can levels use crates like tokio?

Levels are compiled with plain rustc, so no. Async Archipelago comes with runtime.rs, a tiny async runtime built from the standard library that stands in for tokio.

Is it safe to run?

It runs the code you write as you, like cargo run would. The game only listens on 127.0.0.1, its API needs a per-install key, and on Linux each program runs in its own process namespace.

What does Vim mode use?

Your own Neovim, through nvim --embed, with your config by default. It never writes files; the game saves your code itself.

Which systems does it run on?

It's developed and tested on Linux.
